# 쿠폰콕 3분 데모 시나리오

## 시연 목표

**쿠폰 지갑을 보여주는 것이 아니라, 매장에 들어가면 등록 쿠폰을 찾아 계산·추천하는 에이전트**임을 보여준다.

## 사전 준비

1. Xcode에서 Apple Development Team을 선택해 서명 빌드한다. Firebase Auth는 Keychain 권한이 있는 서명 빌드에서 확인한다.
2. 앱 첫 화면에서 `매장 진입 알림`을 켜고 위치는 **항상 허용**, 알림은 허용한다.
3. 시뮬레이터에서는 Features > Location 또는 `simctl location start`로 수원 스타벅스 좌표를 매장 밖에서 안으로 이동한다.
4. 데모 중 네트워크가 불안정할 때만 화면의 `데모: 스타벅스 매장 진입 테스트`를 사용하고, 결과의 **데모 추천** 배지를 함께 설명한다.

## 질문 대비

- **AI가 할인 금액을 지어내지 않나요?** 아니요. 할인·중복·순위는 백엔드 계산기만 결정하고 LLM은 OCR JSON 정규화와 설명만 합니다.
- **쿠폰 사진은 어디에 저장되나요?** 원본은 iPhone 앱 내부에만 둡니다. Firestore에는 사용자가 확인한 구조화 필드만 저장합니다.
- **매장 정보는 어디서 오나요?** 수원시 범위에서 공공데이터포털 상가업소 API를 Cloud Run이 호출하고, 초기 반응성은 iPhone MapKit 탐색으로 보완합니다.
- **통신사 혜택은 믿을 수 있나요?** SKT·KT·LG U+ 공식 페이지 링크를 결과에 표시하며, 구조화된 할인 규칙이 없으면 할인액을 임의 계산하지 않습니다.
