# 제출용 시뮬레이션 실행 안내

일반 실행은 빈 개인 지갑으로 시작하며, Firebase·위치 권한·실제 Cloud Run API를 사용한다. 제출용
시뮬레이션은 **Simulator의 실행 인자에서만** 활성화된다. TestFlight와 실제 사용자 빌드에는 포함되지 않는다.

## Xcode 실행

`Product → Scheme → Edit Scheme… → Run → Arguments`에서 아래 인자를 추가한 뒤 실행한다.

```text
-CouponCokSubmission
```

명령행 실행 예시는 다음과 같다.

```bash
xcrun simctl launch booted com.couponpilot.app -CouponCokSubmission
```

## 발표 흐름

1. 홈에서 10개 이상 프랜차이즈의 보유 쿠폰·만료 임박 항목을 보여 준다.
2. `투썸플레이스 수원시청점 도착`을 탭해 매장 진입 알림과 추천 흐름을 시작한다.
3. 추천 화면에서 Calculator Tool의 최종가(3,100원)·절약액(2,000원)과 AI 설명의 역할 분리를 설명한다.
4. 추천 쿠폰을 열어 바코드·조건을 확인하고, 사용 처리 후 5초 실행 취소 또는 기록 화면의 복원을 보여 준다.
5. 내 정보에서 통신사·멤버십과 카드 상품명만 저장하며 카드번호·CVC·원본 이미지를 저장하지 않는 경계를 설명한다.

## 시뮬레이션 경계

- 수원 기준 매장, 22개 쿠폰, 사용 이력은 발표 재현성을 위한 시드다.
- 추천 수치는 시드 쿠폰의 확정 조건을 기준으로 계산한 결과다. 실제 서비스에서는 Firebase 인증 뒤
  Cloud Run의 Calculator Tool이 최종가와 순위를 확정한다.
- 시스템 알림은 Simulator 알림 권한이 필요하다. 권한을 거부해도 추천 화면은 계속 확인할 수 있다.
- 제출 시 발표자는 위치·쿠폰 시드가 재현용이라는 점을 구두로 고지한다. UI는 실제 사용자의 빈 지갑과
  혼동되지 않도록 실행 인자로 분리돼 있다.
